## 发现与处置

### F1：缺失细胞群标签使稀疏路径新增报错（已修复并通过完整回归）

`cellchat_class.py` 的 `groups` setter 和 `set_identity` 接受 categorical
缺失值。发布版用 `labels == cluster` 选择细胞，因而缺失标签不参与当前组
统计，但细胞仍留在完整置换序列和 population size 分母中。

初审时 `_sparse_quantiles.py:165` 对所有负 group code 抛错，故 sparse
triMean/median 对这类发布版可执行输入新增 `ValueError`；dense 路径和
另外两种平均方法仍沿用发布版行为。这不是原模型定义本身的限制。

最小兼容补丁仅允许缺失标签对应的负 code，在两次稀疏值遍历中跳过
这些条目，并从合法 code 计算 `group_sizes`。不得预先删除缺失标签细胞，
否则会改变置换空间和 population size。未知且非缺失标签仍应报错。
已以固定发布版作 oracle，覆盖两种统计量、dense/CSR、外部固定置换和
全局 RNG 后状态；Python/Numba 两种稀疏核还覆盖全缺失标签和空类别。
无缺失标签时不额外执行整列 `pd.isna` 或有效 code 筛选。

### F2：非整数 dtype 外部置换的全矩阵验证暂存（已修复并通过完整回归）

初审时 `_streaming.py:219-220` 对浮点 dtype 外部置换调用全矩阵 `isfinite`、
`astype(np.intp)` 与比较，因此会临时使用 `O(N*B)` 内存。公开参数描述要求
整数索引，正常整数 ndarray 不走此分支；但实现也接受内容为整数的浮点
数组，不能不加条件地声称所有外部置换都不产生全矩阵复制。

已将验证和类型转换移至每列，保持整值浮点输入可用，使内部暂存为 `O(N)`。
新增 ndarray 转换监控与 finite-mask 监控会直接拒绝二维验证操作；其测试
同时精确对照固定发布版。最后一列包含分数、NaN、Inf 的输入仍被拒绝。
调用者自己提供的 `N*B` 矩阵仍占内存，`np.unique` 逐列验证还有
`O(N log N)` 的排序时间上界。传入 Python 嵌套列表仍须由 `np.asarray`
物化为数组；无整阵复制的保证针对已有 NumPy 数组。

### F3：复杂度说明需要限定执行路径（文档已修订）

`RESEARCH_POSITIONING.md` 原主要循环时间界限应限定为稀疏 triMean/median
及内部置换，不能直接覆盖密集/均值分块回退和外部置换验证。已在该文档
及 `METHOD.md` 中补明这些条件。

另补明裁剪前全部 signaling 表达的提取、格式转换、归一化会产生额外
峰值：其稀疏规模为 `O(Z₀ + G₀ + N)`，密集归一化副本为 `O(N*G₀)`。
裁剪后循环工作内存界限不能代替完整预处理峰值。

## 已核对的计算结构

- 全局归一化最大值在依赖裁剪前取得；CSR 数据直接除以最大值，避开
  SciPy 乘倒数造成的严格置换比较舍入差异。
- 按基因预排序、按当前标签取有序子序列的论证成立。显式零去除后，
  隐式零秩位于负值与正值之间；缺失表达计数与标签缺失是两回事。
- 分位数端点、NumPy 插值分支和 median 的奇偶分支被分别保留；Numba
  没有启用 fastmath。纯 Python 与编译核共用同一算法函数。
- LR/复合物优先级、可用亚基、辅因子列顺序及 Hill 乘法顺序对应固定源码。
  常量 population fractions 可跨置换复用，因为置换不会改变各标签计数。
- 置换表达保持固定，仅改变标签；内部每次全局 RNG 调用和最终状态与
  发布版一致。严格超越规则没有改为容差比较、`>=` 或加一校正。
- LR 张量分块和累计计数消除了随置换次数增长的主要内部存储；输出仍是
  `O(L*K²)`，也仍保留表达数据和有序稀疏计划，绝非常数内存。
- 原实现末尾长表未存储或返回，省去该表不会删除公开结果。

# 教程图形差异说明

最终逐文件核对结果是 **147/148 张 PNG 的 SHA-256 相同**，不能写成 148 张全部相同。唯一不同文件为 `02_nl_ls/tutorial/figures_comparison/cmp_13_bubble_comparison.png`。

根代理对两幅原始图的目视检查发现：部分同一发送者→接收者组合的 NL/LS 横轴列互换，气泡随其样本标签换列；这是实际图像布局差异，不只是 PNG 元数据或压缩差异。

只读代码审查定位到原版 `CellChatPy/visualization.py` 的 `plot_network_bubble`：

- 第 1350、1361–1365 行的排序逻辑先去除样本后缀，排序键仅含发送者和接收者的位置，不包含 NL/LS 样本顺序。
- 第 1388 行使用 `sorted(set(all_st_pairs) | set(...), key=key_fn)`。相同发送者→接收者下的 NL/LS 列具有相同排序键，最终相对顺序继承 `set` 的迭代顺序，因此可能随独立 Python 进程的字符串哈希顺序变化。
- 第 1221–1227 行从各样本概率/P 值矩阵读取数值，并把对应样本名附加到 `source_target`。第 1418 行按同一个完整 `source_target` 在 `st_order` 中定位气泡；第 1471 行也使用同一 `st_order` 设置横轴标签。因此未发现“气泡数据和样本标签错配”的证据。保存对象审计已确认两版输入概率/P 值与标签精确一致。
- 原版另在第 1448–1451 行按第一个样本的列数画分隔虚线，注释假定两组连续排列；这个假设不适用于当前按发送者/接收者交错的列顺序。应把这条线视为已有绘图布局局限，不能据它判断样本归属；应读取各列明确的 NL/LS 标签。

两版整个 `visualization.py` 完全相同，SHA-256 均为 `46df09b26975c34b7fa4b3c24a69c2ee9aebe2641742ac84c6fe5d61253f00ba`。`plot_network_bubble` 函数源码 SHA-256 均为 `b62e9e2280f58cb540dc37d91b0c3a6d4f844a2c0ea4f777139a890ff8648d65`。

**已验证事实**是文件计数、两图成对列换位且标签对应、输入数值一致及绘图源码一致。**代码层面的来源解释**是上述 `set` 加相同排序键的非稳定样本次序；它与本次观测吻合，本次没有额外运行固定哈希种子的因果复现实验。没有证据指向加速引擎造成概率/P 值变化或标签错配。

本说明仅审查已执行的结果与冻结源码；没有修改包、改变科学参数或重跑教程。后续若单独修复绘图可使用稳定去重并加入明确的样本排序键，同时调整分隔线逻辑；本次没有实施该修复。
